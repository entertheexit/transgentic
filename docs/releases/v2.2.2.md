# Transgentic v2.2.2

This patch improves WebView provider compatibility, media handling, and response reliability.

## Provider compatibility

- Restrict model discovery and selection to the active provider's model picker, excluding unrelated menu entries and unavailable choices. Explicit model requests still require a verified selection.
- Update ChatGPT and Gemini attachment readiness checks, including mixed image and document uploads, and refresh Grok's native media availability detection.
- Preserve code language labels and nested backticks in provider responses, and avoid mistaking hidden page content or conversation text for provider notices.
- Preserve the selected media mode during prompt entry and verify the composer-owned send control before submission. Active background WebViews temporarily suspend throttling while a request runs.

## Media reliability

- Allow generated media downloads with larger response headers and report the provider's reply when a media request finishes without an artifact.
- Detect Grok's native media entitlement dialog and return an unavailable result instead of waiting for the generation deadline.

## Availability and verification

Provider availability, quotas, account access and native controls can change. Gemini image generation produced both successful saved images and an intermittent native refusal during verification. Grok image and video reached an account or subscription boundary. A separate Gemini Temporary Chat request timed out even though its native reply appeared. See the [provider health report](../reports/provider-health-2026-10-30.md) for the test evidence and remaining coverage gaps.

The Chrome extension remains at v1.2.0 in this desktop release.
