# Transgentic v2.4.4

- Improved compatibility with Grok Premium’s updated Image and Video composer while retaining support for the earlier layout.
- Fixed an image-saving issue where a reference upload could be saved as the generated result. Transgentic now checks that the saved image comes from the generated response.
- Improved Grok CLI session continuity and isolation. Separate conversations keep their own session state, and text attachments are passed through to the CLI.
- Restored bundled model-picker settings when an older locally healed recipe is missing them.

Grok’s updated media composer handles some settings through prompt instructions. The provider may return a different aspect ratio or resolution from the one requested.
