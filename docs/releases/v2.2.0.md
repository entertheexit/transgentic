# Transgentic v2.2.0

This release adds configurable media generation across Quick Prompt, MCP, and an authenticated HTTP API, improves provider response reliability, and makes the desktop interface easier to read at larger window sizes.

## Media generation and settings

- Generate images, videos, and music through recipe-controlled provider tools. Supported settings are discoverable per provider and model, with verified defaults applied before each request.
- Quick Prompt's sparkle button now opens generation settings. Save choices per provider and mode, configure fallback overrides, or reset to recipe defaults. Unsupported inherited settings explain why a fallback will be skipped.
- Added Gemini image aspect ratios, video orientation, and music length, vocals, and genre controls. Music defaults to Standard length with Custom vocals and genre; images default to square and videos to landscape.
- Added Grok Imagine image and video settings. Images default to Speed and square; videos default to 480p, six seconds, landscape, and sound enabled. Video generation requires the provider's applicable account entitlement.
- ChatGPT image generation uses native automatic settings. Reference uploads are supported where declared by the selected provider.
- Generation succeeds only when usable media is saved and validated. Text-only replies are reported as `media_not_generated`. Music remains in the Music library even when delivered as an MP4 with an audio track.

## Media API and MCP

- Added authenticated capability discovery and asynchronous media jobs: create a job, check progress and effective settings, cancel or stop waiting, and download its registered artifacts.
- Jobs and idempotency keys persist across restarts. Interrupted submissions become uncertain instead of being replayed, and differently configured requests retain distinct identities.
- MCP generation and editing tools accept the same settings and provider overrides, with reference attachments for supported image and video workflows.
- Existing chat completions remain available with their current contract. See the [Media API guide](../MEDIA_API.md) for endpoints, defaults, authentication, and examples.

## Provider and integration reliability

- Improved completion response parsing and tool-call handling, including JSON escapes, Markdown, code, and explicit tool selection used by agentic clients.
- Improved ChatGPT image completion detection so finished generations can leave the processing state and be collected.
- Response capture ignores hidden conversation content and duplicate hidden editors across ChatGPT, Claude, Gemini, and Grok.
- Sign-in and verification challenges surface as actionable errors while waiting for a response. Ordinary conversation text quoting those notices is not treated as a verification challenge.
- Requests that may already have been submitted stop automatic fallback, including normal chats and callers sharing an in-flight request, to prevent duplicate submissions.
- Improved temporary-chat handling, attachment validation and reporting, and native CLI provider connection diagnostics.

## Desktop interface

- App text and controls scale with the main pane, up to 25% larger, while compact windows retain the baseline size. Embedded provider pages retain their own scaling.
- Improved window resizing and drawer layout management.
- Windows and Linux use nearly opaque backgrounds for readability where native macOS vibrancy is unavailable. macOS retains its native vibrancy behavior.
- Updated the README, API documentation, and Settings API guide for media workflows.

## Availability

Provider controls, quota, subscriptions, and sign-in requirements still determine which generations are available. Grok video controls are included, but video generation was not live-tested on the current free account. Windows appearance still needs verification on a Windows device.

The Chrome extension remains at v1.2.0 in this desktop release.
