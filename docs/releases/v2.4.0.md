# Transgentic v2.4.0

This release expands model discovery and routing across web providers and native CLIs, adds per-model thinking effort, and improves media and response handling.

## Model discovery and routing

- Refresh model catalogs from supported provider pickers and native CLI services, then expose the discovered choices for routing. Discovery is performed by Transgentic and does not require agent-driven computer use.
- Configure a default model and ordered model fallbacks for each provider and task mode. Provider routing can also supply ordered model overrides for one request.
- Add combined model-and-effort choices, including ChatGPT thinking effort and supported Claude and Gemini effort levels. Existing separate `model` plus `reasoning_effort` requests remain supported.
- Expand the MCP and OpenAI-compatible APIs with model listing, route inspection, per-request model selection, ordered model lists, and provider-keyed model overrides.
- Apply model selection to WebView and CLI requests while validating that explicit models are available for the requested provider and mode.

## Provider and response improvements

- Refresh built-in provider recipes and model-picker handling for current web interfaces.
- Improve WebView input readiness, attachment handling, request completion detection, and response capture, including fenced code blocks and whitespace preservation for custom web providers.
- Improve media capability reporting and model compatibility checks for image, video, and music workflows.
- Preserve provider-specific model and effort information in completion metadata.

## Availability and notes

- Available models, effort levels, media modes, account entitlements, and quotas depend on each provider's current interface and signed-in account.
- Custom web providers can generate images and videos when the recipe and account support them. Music generation was checked against the live provider and returned `MUSIC_GENERATION_UNAVAILABLE`; it is not enabled by this release.
- Custom recipes remain user-managed and are not bundled as built-in recipes in this release.
- The Chrome Sync extension remains at v1.2.1.

## Verification

Release preparation updates the desktop version metadata and release notes. Build, automated tests, live provider verification, signing, and publication are separate checks and are not implied by this note.
