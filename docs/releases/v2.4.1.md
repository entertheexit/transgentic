# Transgentic v2.4.1

## Routing and model selection

- **Current** uses the model and thinking effort selected in the provider. Routing shows verified model and effort combinations, such as **3.1 Pro Low** and **GPT-5.6 Sol Medium**.
- ChatGPT Image Routing offers the model and thinking-effort choices discovered in the account. Named MCP requests select the model and effort in the isolated image composer before submission.
- Updated ChatGPT’s model picker and Gemini’s **Thinking level** submenu. MCP and the OpenAI-compatible completion API accept a combined model ID or separate `model` and `reasoning_effort` fields.
- Fixed Gemini’s model picker detection when sidebar controls had similar labels. Background model discovery keeps its browser view separate from active requests so Transgentic can collect the provider’s reply.

## Image generation and chat status

- Fixed ChatGPT image requests by updating the **Create image** action and verifying the composer and draft before submission. Older repaired recipes receive the updated image action when loaded.
- Normal ChatGPT Image requests through MCP use a separate composer to preserve drafts in the ChatGPT drawer. If a request times out or is cancelled during execution, Transgentic discards that composer so the next request can open a clean one.
- ChatGPT Image defaults to Normal chat, and its Temporary Chat UI controls are disabled. ChatGPT does not expose **Create image** in Temporary Chat for the tested session.
- Improved detection of Gemini’s normal chat control. An unverified Temporary Chat check displays a neutral status in Normal mode and a warning when Temporary Chat is requested.
- Chrome Sync checks for a signed-in Gemini tab before transferring cookies and reports the transfer as **Session Cookies Imported**. The Gemini drawer shows whether the copied session is signed in.
- Provider health checks give web apps more time to mount their prompt controls before reporting missing elements.

## Verified workflows and availability

- Gemini **3.1 Pro Low** appeared in General Routing and returned live replies through both MCP request formats on a synced account.
- A ChatGPT image request completed through MCP and saved a PNG. ChatGPT disabled **Create image** in the tested Temporary Chat session, and Transgentic reported that restriction.
- A separate signed Apple Silicon verification build used a four-second deadline for one ChatGPT Image request. After it timed out, the same app process retried with the normal deadline and saved a readable 1254 × 1254 PNG. The test used a separate profile and Library.
- ChatGPT’s available model and effort combinations depend on the account. GPT-5.6 Sol Instant, Extra High, and Pro were unavailable for verified selection in the tested session.
