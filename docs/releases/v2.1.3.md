# Transgentic v2.1.3

This patch improves webview chat and attachment reliability across the built-in providers, and makes the active route easier to see in the Hub.

## What's changed

- Refreshed the built-in ChatGPT and Grok chat controls, plus attachment controls for ChatGPT, Claude, and Gemini. Uploads with declared readiness checks now wait for the provider to show the file as ready before sending a prompt, and ambiguous file inputs fail safely.
- Fixed background self-healing checks interrupting active chats. These checks no longer open attachment menus or send Escape while a provider is responding.
- Improved new-chat and temporary-chat handling. A failed navigation or submit now stops the request instead of treating an old conversation as the new chat, and ChatGPT temporary chats retain their verified identity when the provider replaces a provisional conversation URL.
- Updated response detection for current ChatGPT and Grok layouts, and kept managed chat windows separate from shared provider views during navigation and session refresh.
- The Hub now shows the active mode and its configured primary service, such as **General (ChatGPT)**.

The Chrome extension remains at v1.2.0 in this desktop release.
