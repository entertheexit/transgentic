# Transgentic v2.3.0

This release adds Meta AI, packages Chrome Sync 1.2.1, improves Antigravity quota handling, and adds explicit ChatGPT Temporary Chat personalization choices.

## Meta AI

- Add Meta AI as a built-in provider with isolated accounts, native model discovery, provider settings, routing selection, `ask_meta`, and `/meta/mcp` and `/meta/sse` endpoints. Existing route defaults are preserved.
- Enable image generation, video generation, image editing and image-to-video. Text, image and video requests accept one PNG, JPEG or WebP reference image. Documents, video-file uploads and multiple references are not advertised.
- Preserve inline reference images while entering prompts and wait for stable upload readiness before submission. Distinguish generated and edited outputs from reference previews.
- Validate downloaded images and playable video before reporting success. Improve WebP decoding, media file extensions, request-view ownership and video completion detection.
- Restrict authentication checks to the signed-in account marker and correct origin. Filter download cookies to their destination and remove them on cross-origin redirects.

## Chrome Sync 1.2.1

- Add Meta AI to the existing shared authentication extension, including manual session transfer and optional background refresh.
- Limit Meta imports to Meta AI cookie domains. Background refresh defaults off and requires an open signed-in Meta tab; guest pages cannot establish authentication.
- Include `transgentic-sync-v1.2.1.zip` in desktop packages and as a separate release asset. The desktop ZIP download uses the matching version.

After updating Transgentic, reload the existing unpacked Chrome Sync extension from the updated folder, or replace it using the new ZIP. Sync your signed-in Meta AI tab to the running application. Existing provider authentication continues through the shared extension.

## Antigravity quota handling

- Detect Antigravity's hard `RESOURCE_EXHAUSTED (code 429): Individual quota reached` diagnostic promptly instead of leaving the request retrying until a generic timeout.
- Show a quota-exhausted state and preserve the quota reset time when the native CLI reports one. Keep quota exhaustion distinct from authentication failure.
- Sanitize diagnostics rather than returning native logs or request content. Transient startup login messages and retryable rate limits do not trigger the hard-quota path.

This reports the native account limit; it does not bypass quotas. Wait for the reset or select another model/account in the native CLI.

## ChatGPT Temporary Chat personalization

- Add Normal, Temporary — Personalized, and Temporary — Unpersonalized choices in Home and Settings, remembered per provider and task mode.
- Present the selected mode as clickable text with a chevron and popover menu. A colored status circle exposes availability details on hover or keyboard focus; recovery actions live inside the menu.
- Expose exact choices to clients through `chat_mode: "temporary-personalized"` and `chat_mode: "temporary-unpersonalized"`. The existing `temporary_chat` boolean remains supported; true selects Personalized on ChatGPT, and false selects Normal.
- Recheck Temporary Chat availability in a hidden account-isolated page without opening the provider drawer or disturbing an active conversation. Loading and inspection are bounded; stale account/recipe results are discarded.
- Verify native Temporary Chat and personalization before uploads, typing, submission and continuation. Missing or ambiguous controls fail closed; an exact selection does not silently fall back to another mode.
- Activate native personalization menus that open on pointer-down, including switching between ChatGPT's Personalized and Unpersonalized modes.
- Isolate conversation history when selections change and report requested/actual selections in execution metadata. Existing true/false ChatGPT preferences migrate to Personalized/Normal respectively.
- Default new Coding configurations to ChatGPT Unpersonalized; preserve existing choices. Show Temporary Unavailable for CLI and API services, whose own settings govern history and personalization.
- Skip generated Recall instructions for unpersonalized or generic Temporary chats; allow them for explicitly Personalized ChatGPT and report the effective decision per execution branch.

Personalization follows each provider's native behavior. Temporary mode does not disable Transgentic's local logging or Library storage. Availability depends on the signed-in account and the provider's current controls.

## Verification and limits

- Full regression suite: 796 passed, 12 skipped. Real Electron/Chromium fixture harness: 37 checks passed at compact and desktop widths. A separate hidden-page Electron check verified active-session reuse, hydration, cleanup, read-only availability inspection and pointer-driven personalization menus.
- Restarted desktop verification: both ChatGPT selections reported availability from the Hub without opening a provider page. Live requests for Personalized and Unpersonalized completed with matching requested/actual selections and verified native Temporary Chat.
- Meta AI was tested through authenticated Electron MCP execution, including a fresh Chrome Sync transfer and newly saved/decoded image, video and edited-image artifacts. Two fresh image-to-video requests produced validated MP4s. Their observed ten-second duration is not a supported duration-setting guarantee.
- Antigravity quota handling has automated regression coverage; it was not re-tested against an authenticated live provider during this release preparation.
- Provider quotas, temporary service failures, account entitlements and native UI changes still apply. Meta Music and native Temporary Chat are not advertised.
