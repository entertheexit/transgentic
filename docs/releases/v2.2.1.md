# Transgentic v2.2.1

This patch refreshes built-in web-provider recipes and model selection for current provider interfaces, and fixes several paths that could report success without a usable result.

## Provider compatibility

- Discover named web models from the signed-in provider's current picker. Explicit model requests now require a visible, verified selection before a prompt is submitted; saved choices remain available to select again when rediscovered.
- Update Gemini's model picker, ChatGPT's image composer, and Grok's chat and Imagine controls for their current layouts. Grok image and video generation were verified on a free account.
- Preserve fenced code blocks in ChatGPT, Claude, Gemini, and Grok coding responses instead of joining the language label and code as plain text.
- Wait for animated media menus to settle before resolving controls, while still rejecting ambiguous settings.
- Improve Temporary Chat status in the Hub: checking or currently unavailable capabilities no longer appear as *Unsupported*, and an enabled preference can be turned off even when the provider becomes unavailable. A healed built-in recipe inherits the bundled Temporary Chat declaration when it omits one.

## CLI and maintenance

- Allow Antigravity's headless editing and command tool prompts only for actions the caller has enabled; the existing workspace sandbox still applies. Live disposable-project checks passed answer, resume, edit-only, command-only, and combined edit/command paths for both Antigravity and Codex.
- Add a [weekly provider health-check runbook](../PROVIDER_HEALTH_CHECK.md) covering built-in modes, model selection, privacy modes, native CLIs, media settings, transports, and custom recipes. The [dated verification report](../reports/provider-health-2026-10-15.md) records the tested paths and remaining gaps.

## Availability and known limitation

Provider controls, quotas, subscriptions, and sign-in state determine which modes are available to each account. Gemini Temporary Chat worked in an earlier native-browser check, but the current embedded Gemini view did not expose an activation control for a preference-enabled Coding request, so Transgentic stopped before submission. Use Gemini with Temporary Chat off until that provider path is reverified; the request is not silently sent as a normal chat.

The Chrome extension remains at v1.2.0 in this desktop release.
