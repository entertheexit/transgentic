# Transgentic v2.4.3

- Improved Chrome Sync compatibility. The provider drawer uses its embedded Chromium version when synced Chrome reports a different major version.
- Preserved Google's security response headers in embedded sessions and limited default navigation headers to top-level requests.
- Improved Gemini Video error handling. Transgentic can recognize a completed failure even if Gemini leaves the Stop button visible, including when Gemini reports that video generation is at capacity.

Fully quit and reopen Transgentic after updating. See [Chrome Sync and browser compatibility](../CHROME_SYNC.md) for troubleshooting.
